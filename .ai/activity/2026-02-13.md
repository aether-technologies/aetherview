# 2026-02-13 - Article Template Implementation

## Task
Create an HTML template and CSS for AetherView articles so markdown-generated content matches the site's look and feel.

## Stage: Implementation (Complete)

### Files Created
- `www/articles/template.html` — Reusable template with `{{PLACEHOLDER}}` tokens for the build script to populate
- `www/css/article.css` — Article-specific CSS scoped to `.article-body` for styling raw markdown HTML

### Files Updated
- `www/articles/quitgpt_the_campaign_to_ditch_chatgpt_over_openais_political_ties.html` — Applied template
- `www/articles/spacex_xai_musk_signals_ai_alliance_that_could_reshape_the_race.html` — Applied template

### Template Placeholders
- `{{ARTICLE_TITLE}}` — Article title
- `{{ARTICLE_EXCERPT}}` — Short description / excerpt
- `{{ARTICLE_TOPICS}}` — Comma-separated topic keywords
- `{{ARTICLE_AUTHOR}}` — Author name
- `{{ARTICLE_DATE}}` — ISO date (YYYY-MM-DD)
- `{{ARTICLE_DATE_DISPLAY}}` — Human-readable date (e.g., "February 12, 2026")
- `{{ARTICLE_READ_TIME}}` — Estimated read time in minutes
- `{{ARTICLE_TOPICS_HTML}}` — Topic spans: `<span class="meta-topic">Topic</span>`
- `{{ARTICLE_CONTENT}}` — The raw markdown-generated HTML to insert

### Design Decisions
- Template is a full standalone HTML document (articles are not loaded via SPA router)
- All article body styles scoped under `.article-body` to avoid conflicts with base styles
- Restored list styling (disc/decimal) within articles since base CSS removes it
- Gradient h1 title matches site branding
- Responsive design with breakpoints at 768px and 576px
